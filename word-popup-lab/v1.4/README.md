# Word 只读选字弹窗修复候选 V1.4

V1.3 已在真实 Word 中复现：普通文件复制正常，只读文件选字触发“使用 Office 连接体验”。

本版只测试 Word 二进制中实际存在的功能标识 Microsoft.Office.Word.EnableCopilotOptionsInSelectionFloatie，将对应外部实验覆盖字符串设为 false。此值尚未证明有效，不应提前作为用户修复方案。

依次验证普通文件、默认只读、候选修改后的两次只读、恢复原值后的只读。只有“原本弹窗→两次无弹窗且复制正确→恢复后再弹窗”、文件仍只读且四个连接体验禁用策略不变，才标记测试环境修复成立。全程仅合成文本、临时托管虚机，不使用账号和用户文件。
