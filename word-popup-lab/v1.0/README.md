# Word 只读选字弹窗复现实验 V1.0

流程：检查 Windows → 检查输入桌面 → 检查桌面版 Word → 检查授权与账户环境 → 复现选字弹窗 → 验证修复。

目标：保留文件只读属性、关闭 Office 可选连接体验、保留 OneDrive 本地同步，选字复制不再弹出连接体验提示。

当前提交只执行环境检测，不安装 Office，不修改隐私设置，不读取用户文档，不代表已复现或已修复。缺少条件时明确返回失败码 2，并保存 `environment.json`、`RESULT.md`。

## 判定规则

- Windows 工作流执行成功，不等于 Word 故障复现。
- 未捕获目标弹窗，不得标记 `reproduced=true`。
- Word 未激活、未登录、产品/账户环境不一致时，不得把“不弹窗”判为修复。
- 不以启用连接体验、移除只读属性、改变 OneDrive 同步方式为修复。
- 真正的界面复现需要已授权的桌面版 Word 与可交互 Windows 会话。

## 状态

此版本用于实测 GitHub 托管 Windows 运行器是否具备复现前提。真实运行结果以 Actions 日志和附件为准。
