# 真实 Word 界面试验 V1.1

流程：官方 ODT 安装家庭版产品 → 在临时运行器关闭连接体验 → 创建合成文档 → 可写/只读对照 → 键盘选字 → 捕获目标弹窗和界面证据。

只允许在一次性 GitHub 托管 Windows 运行器执行。不会登录微软账户、接触用户文件或上传用户凭据。安装不等于激活；未激活、未登录 OneDrive 的阴性结果仅记为 `INCONCLUSIVE`，不得宣称修复。

V1.0 实测已确认托管 Windows 2022 有可交互 Default 桌面，但未安装 Word。V1.1 继续验证官方安装和实际 Word 界面，不因缺少预装 Word 停止。

脚本只采集安装元数据、合成文档界面及 Office 中已观察到的功能标识符；不据猜测批量修改未知注册表键。
